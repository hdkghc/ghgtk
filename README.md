# ghgtk

A fast, native GitHub client built with GTK3 and WebKit2GTK.

![License](https://img.shields.io/badge/License-GPLv3-blue.svg)
![C++](https://img.shields.io/badge/C++-17-blue.svg)
![GTK](https://img.shields.io/badge/GTK-3.0-brightgreen.svg)

## Features

- **Repository Search** – Search GitHub repositories with instant results
- **Release Management** – Browse, view, and download releases with assets
- **Markdown Rendering** – Full CommonMark support via cmark, rendered with WebKit2GTK
- **Parallel Loading** – Multi-threaded fetching for fast release loading
- **Asset Download** – Select individual files or download all assets
- **Clone Repository** – Clone repositories with a single click
- **Link Preview** – Hover over links to see the URL in the status bar
- **Progress Tracking** – Visual progress bars for all long-running operations
- **Debug Console** – Built-in debug output for troubleshooting

## Installation

### Ubuntu/Debian

```bash
# Install dependencies
sudo apt update
sudo apt install -y libgtk-3-dev libwebkit2gtk-4.1-dev libjson-c-dev libcmark-dev

# Build
g++ -o ghgtk ghgtk.cpp `pkg-config --cflags --libs gtk+-3.0 webkit2gtk-4.1` -ljson-c -lcmark -std=c++17 -pthread

# Run
./ghgtk
```

### Authentication

ghgtk relies on GitHub CLI (`gh`) for authentication. Ensure you have logged in:

```bash
gh auth login
```

### Arch Linux

```bash
sudo pacman -S gtk3 webkit2gtk json-c cmark github-cli
g++ -o ghgtk ghgtk.cpp `pkg-config --cflags --libs gtk+-3.0 webkit2gtk-4.1` -ljson-c -lcmark -std=c++17 -pthread
```

### Fedora/RHEL

```bash
sudo dnf install gtk3-devel webkit2gtk4.1-devel json-c-devel cmark-devel gh
g++ -o ghgtk ghgtk.cpp `pkg-config --cflags --libs gtk+-3.0 webkit2gtk-4.1` -ljson-c -lcmark -std=c++17 -pthread
```

## Usage

### Search for Repositories

1. Enter a repository name in the search box
2. Press Enter or click "Search"
3. Double-click any result to view its releases

### Browse Releases

1. Select a repository from the search results
2. The Releases tab displays all available versions
3. Click a release to view:
   - Available assets in the "Assets" panel
   - Release notes rendered as Markdown

### Download Assets

1. Select a release from the list
2. Click individual assets to select them, or leave all selected
3. Click "Download" and choose a destination directory
4. Files are downloaded using `gh release download`

### Clone Repository

1. Navigate to the Releases tab
2. Click "Clone" and select a destination directory
3. The repository is cloned using `gh repo clone`

## 使用说明

### 搜索仓库

1. 在搜索框中输入仓库名称
2. 按 Enter 键或点击“Search”按钮
3. 双击任意搜索结果以查看其 Release

### 浏览 Release

1. 从搜索结果中选择一个仓库
2. Releases 标签页将显示所有可用版本
3. 点击某个 Release 可查看：
   - “Assets”面板中的可用附件列表
   - 渲染为 Markdown 的 Release 说明

### 下载附件

1. 从列表中选择一个 Release
2. 点击单个附件可选中，不选择则默认下载全部
3. 点击“Download”并选择目标目录
4. 文件将通过 `gh release download` 下载

### 克隆仓库

1. 切换到 Releases 标签页
2. 点击“Clone”并选择目标目录
3. 仓库将通过 `gh repo clone` 克隆
